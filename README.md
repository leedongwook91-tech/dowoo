# 모아 — 학생 웹 앱 전시

학생은 공개된 웹 앱 주소를 등록하고, 관람객은 카드를 눌러 새 탭에서 방문합니다. PDF 기획서는 선택 사항이며 브라우저에서 볼 수 있습니다. 앱 파일 업로드와 다운로드 버튼은 없습니다. 브라우저의 기본 PDF 저장 기능까지 차단하지는 않습니다.

## 실행
Node.js 20 이상에서 `npm start`로 실행합니다. 외부 패키지는 필요 없습니다. 기본 포트 3000, `PORT`로 변경 가능. `npm run check`, `npm test`로 검증합니다. 화면의 여섯 작품은 실제 앱 주소가 없는 예시입니다.

## Render 무료 + Supabase 무료 한도 내 저장
Render 무료 서버에는 파일을 영구 보관하지 않습니다. 작품 제목·소개·앱 주소는 Supabase 데이터베이스, PDF는 Supabase Storage의 비공개 버킷에 저장합니다. 서버가 재시작되어도 Supabase 데이터가 유지됩니다. 무료 서비스의 용량·트래픽 제한 및 비활성 프로젝트 일시중지는 서비스의 현재 정책을 확인하세요. 무제한 또는 영구 무료를 보장하지 않습니다.

1. Supabase 계정에서 새 프로젝트를 만듭니다.
2. SQL Editor에서 `supabase/setup.sql` 내용을 실행합니다. 테이블과 PDF 버킷이 생성됩니다. 공개 접근 정책은 추가하지 마세요.
3. Supabase 프로젝트 설정에서 Project URL과 서버 전용 `service_role` 키(legacy API keys)를 확인합니다.
4. Render의 해당 서비스 > Environment에 `SUPABASE_URL`과 `SUPABASE_SERVICE_ROLE_KEY`를 입력하고 저장·재배포합니다. **키는 GitHub, HTML, 채팅에 넣지 마세요.** Render 서버에서만 사용합니다.
5. Render의 Build Command는 `npm install`, Start Command는 `npm start`, 요금제는 Free로 설정합니다. 별도 디스크가 필요 없습니다.
6. 등록 창에 ‘연결된 저장 서비스에 보관됩니다’가 나타나는지 확인하고, 작품과 PDF를 등록합니다. Render를 재시작한 뒤 작품과 PDF가 계속 보이는지 확인합니다.

두 변수가 없으면 임시 로컬 모드로 동작하고 등록 화면에 자료가 사라질 수 있다는 안내가 나옵니다. 한 변수만 있으면 설정 오류로 시작하지 않습니다. 기존 로컬 자료는 자동으로 이전하지 않으므로 연결 전에 등록한 자료는 다시 등록해야 합니다.

## 공개 운영 범위
현재 등록은 계정 없이 가능합니다. 수업 중 제한된 사용을 위한 프로토타입입니다. 널리 공개하기 전 인증, 관리자 검토/삭제, 요청 제한과 파일 검사를 추가하세요. 외부 웹 앱의 내용과 작동 여부는 각 제작자가 관리합니다.
