# 모아 — 학생 웹 프로젝트 전시

Node.js 20 이상에서 외부 패키지 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000입니다. `PORT`로 변경할 수 있습니다. `npm run check`는 서버와 브라우저 스크립트 문법을 검사합니다.

작품 검색, 분야별 필터, 이름순 정렬, 상세 보기, 웹 앱 링크와 기획서/앱 파일 업로드를 지원합니다. 기획서는 PDF/PPT/PPTX/DOC/DOCX, 앱은 ZIP/HTML을 각각 10MB까지 등록할 수 있습니다. 파일과 메타데이터는 `data/`에 보관되며 서버 재시작 후에도 유지됩니다. HTML을 포함한 업로드 파일은 실행하지 않고 다운로드로 제공합니다. 화면에 표시한 여섯 작품은 예시이며 실제 업로드와 구별됩니다.

현재는 계정 없는 공개 전시용 프로토타입입니다. 운영 배포 전에는 인증, 관리자 검토/삭제, 업로드 악성 파일 검사, 요청 제한, 영구 볼륨과 백업을 추가해야 합니다. 인터넷 접근 가능한 서버에 배포해야 여러 학생이 함께 사용할 수 있습니다.
